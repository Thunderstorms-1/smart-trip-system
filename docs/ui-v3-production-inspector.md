# V3 正式工作台迁移记录：Phase 2C

日期：2026-10-07。分支：`feat/ui-v3-production`。本轮基线：`555ff96`。本文记录当前本地 Phase 2C 实现与验证；独立本地检查点的具体 hash 以最终 Git 记录为准，没有推送或部署。

## 范围与设计依据

本轮将已有完整节点字段从时间轴行内编辑迁入桌面右侧 Inspector，并在手机使用 Bottom / Full Sheet。属于已批准 V3 世界的普通迁移，根 `DESIGN.md` 与已批准静态工作台继续作为依据，没有建立新方向或新设计合同。根设计、PRODUCT、sidecar、静态原型及 Home 不在写入范围；未生成新素材或复制演示地图、道路、路线、天气和 POI。

生产改动集中在 `Editor.vue`、`workbench-v3.css`、`workbench/{NodeInspector,NodeFields,PlanEditor,TimelineNode,WorkbenchShell}.vue` 与新增 `workbench/scrollLock.ts`。新增 Inspector E2E 与滚动锁单元测试；既有 Insight / Workbench 测试适配新的编辑位置及路由、字体加载等待。Provider、地图天气、AI、后端和 Quality 业务逻辑不改。

## 同一草稿与完整字段

- `PlanEditor` 直接从当前日期的真实 `trip.days[].items` 查找选中节点，通过延后 Teleport 传入同一响应式对象；没有复制 Inspector 草稿或另建提交状态。
- 复用 `NodeFields` 原字段绑定：地点 / 活动、类型、用户确认的活动环境、固定安排、开始时间、停留小时、预估费用、备注、交通提示，以及原 POI 身份和费用记录入口。费用小数、小时小数和已有数据不因迁移丢失；名称修改仍按原规则清除地点引用。
- 重排移动同一节点对象，选中身份与 Inspector 保持；删除清除选择并将焦点交给最近节点，空日回到添加入口。
- 跨日移动仍移动同一对象，保持原行为：停留当前日期、清除选择、关闭 Inspector 并聚焦添加入口；进入目标日期后可以继续编辑该节点。
- 保存继续调用 Editor 已有整份路书保存流程。保存后的真实节点 ID 由原选择重绑定逻辑接续，新增节点从前端草稿身份切换为持久化身份，Inspector 字段与焦点保留。收起编辑只关闭面板，不丢弃未保存修改。
- 只读权限、忙碌状态、草稿、版本冲突、显式重试和历史入口沿用既有流程。手机 Sheet 内“保存路书”调用同一根保存方法，错误由原错误状态显示于 Sheet，不建立节点单独提交接口。

## 桌面与移动操作

桌面 Inspector 使用非模态原生 dialog，位于工作台右侧，时间轴节点保持紧凑。701–1000 px 调整右侧宽度与时间轴空间；不将完整字段长期展开在时间轴中。Inspector 打开时隐藏原洞察展示，但 Quality 组件仍挂载，报告状态与失效逻辑保持。

700 px 及以下使用原生 `showModal()`：默认底部面板高 72dvh，可展开至接近全屏；字段内容独立滚动，标题与保存区保持可达，底部计入安全区。显式 Tab 焦点约束、Escape、关闭按钮和遮罩外点击关闭均已实现；关闭后焦点返回选中节点。手机打开 Inspector 时隐藏时间轴，保持一个主要编辑面板。

新增共享滚动锁按 owner Set 管理 Inspector 与原 POI / 历史弹窗：各面板仅释放自己的锁，最后一个关闭时恢复此前的 body overflow。屏幕宽度切换会调整模态与锁状态，嵌套弹窗关闭不会提前解锁仍打开的 Sheet。样式限定在工作台，保持跨路由 Home 样式隔离。

## 复现步骤

1. 登录并打开已有可编辑路书，选择一个时间轴节点；确认完整字段出现在右侧，时间轴名称随草稿编辑更新，但保存前后端仍为旧值。
2. 修改备注、重排并保存，核对节点 ID、费用小数、小时小数、交通提示和固定状态保留；收起编辑后焦点返回该节点。
3. 将节点移至另一天，确认停留原日并聚焦添加入口；切至目标日期重新选择，确认修改仍在。删除选中节点，验证最近节点与空日添加入口的焦点。
4. 在手机添加节点、展开 Full Sheet、编辑并保存，确认获取真实 ID 后字段和焦点保持；反复 Tab 不离开 Sheet，Escape 恢复页面滚动与节点焦点。关闭再打开，未保存修改仍保留。
5. 在窄屏与桌面之间切换；通过测试中模拟的前端地点能力打开既有 POI 弹窗，关闭嵌套弹窗后外层 Sheet 仍锁定滚动。该步骤只验证 UI 生命周期，不代表真实 Provider 验收。

## 既有系统摘要与未修复漂移

- 色彩沿用冷浅环境、白色稳定工作面、深蓝灰正文与操作色。
- 字体沿用 Inter 与中文后备；Inspector 标题为 19 px，手机 18 px，辅助信息 12 px，窄屏字段延续 16 px。
- 桌面保持画布 → 日期 / 时间轴 → 右侧功能面的空间关系。
- 密集编辑内容使用不透明可读表面、独立滚动与固定边界区，不把玻璃材质用于长表单。
- 手机通过 Bottom / Full Sheet 重组编辑，并保留键盘焦点、安全区与关闭回返。

Detector 仅运行一次，报告两条既有 Inter 常见字体 warning，作为已批准字体保留。预存元数据漂移仍为根 `DESIGN.md` 使用项目原则格式、未采用 Impeccable YAML / 八章节结构，且 `.impeccable/design.json` 不存在。本轮仅记录，不修复或将漂移固化为新规则；不改 Quality 评分、失效逻辑或原有真实数据边界。
