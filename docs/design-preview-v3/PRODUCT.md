# SmartTrip V3 静态设计原型

本文件只约束 public/design-preview-v3 的两个预览，不声明正式产品已经迁移。

## 用户与任务

面向规划旅行的游客。Home 展示一份四天旅程与路线，让用户进入演示工作台；Workbench 帮助查看日期/时间轴、选择地图节点和预览局部编辑。

## 已确认承诺

沉浸摄影、少量透明层、冷白内容节奏、图像化信息。地图作为工作台画布，左侧窄日期栏、浅色时间轴和右侧洞察/Inspector。手机使用单独构图和底部抽屉。排版为清洁产品 UI，无暖纸宋体方向。

## 数据与边界

全部路线、地点坐标、天气、评分和 AI 建议均为静态示意。摄影为生成概念图，并非真实大理影像。编辑只在当前页面内存生效，刷新恢复。无后端、供应商服务、地图 SDK、凭证或持久化。原型不保证导航、开放时间、天气或旅行准确性。

只新增独立预览与预览范围文档；保留所有正式页面、业务、路由及 V2 原型。用户视觉验收后才能另行决定正式迁移。
