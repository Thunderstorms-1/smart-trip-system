# SmartTrip V3 static design preview

Confirmed by user 2026-10-06. Build path: code-led, two isolated static pages; generated photography is an asset, not a UI comp. No production adoption. Home mode Persuade; Workbench mode Operate. Audience: travelers arranging and revising a trip; task: see the travel route, select a day/node, inspect an arrangement. All route, weather, metric and AI values are synthetic demo material.

## Direction contract

THESIS: Make the journey itself the visual protagonist. Home opens on photography crossed by a memorable multi-stop route; Workbench keeps an uncovered map corridor between floating tools. Refuse left-copy/right-photo heroes, equal feature cards and central expanded forms.

OWN-WORLD: Cool slate, photographic lake blue, cold white and route orange. Few transparent surfaces for floating navigation/status/planning; solid white readable timeline and Inspector. Clean sans typography supports pins, distances, miniature routes and schedule graphics. No warm paper or serif display.

STORY: Understand a four-day journey through a plotted route, enter its static planning canvas, select a stop, inspect/edit demo values locally. Clearly separate prototype values from verified travel data.

FIRST VIEWPORT: Desktop Home has edge-to-edge lake photography, small upper-left heading, a dominant sweeping route in its middle/right, and a compact bottom planning control. Cold white content begins directly below. Workbench has a narrow far-left day rail, 330px floating timeline, broad visible central map and 290px right insight/Inspector. Phone has an independent route composition and map with bottom sheet, never a vertical stack of desktop panels.

FORM: User-pinned Immersive Travel Glass UI + Map-first Travel OS, explicitly confirmed with three added constraints. No new concept tournament; the earlier launcher failed and remains unavailable. Signature interaction: selecting a timeline row or map pin selects the same local node and replaces right insights with the Inspector; on phone it opens a focus-managed sheet. Route strokes receive one restrained reveal; reduced motion gets a static route.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Scope and acceptance

Only public/design-preview-v3 and docs/design-preview-v3 are added. Preserve all production files and V2 prototypes. No network APIs, SDKs, credentials, local persistence or business migration. Capture Home and Workbench at 1440px desktop and 390px phone, plus node-selected Inspector at both widths. Human visual acceptance remains pending after local delivery. Existing .agents files are user-owned and untouched.
