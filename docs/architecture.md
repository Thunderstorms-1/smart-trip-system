# 智游伴路：业务与架构

## 模块联动

~~~mermaid
flowchart LR
  P[个人资料与旅行偏好] --> A[AI任务/手动创建]
  A --> T[私密路书 Trip/Day/Item]
  T --> G[真实地点引用/路线/天气]
  T --> E[预估费用与实际记账]
  T --> R[版本记录与恢复]
  T --> S[显式发布公开快照]
  T --> H[独立可撤销分享快照]
  S --> I[点赞/收藏/评论]
  S --> C[克隆为新的私密路书]
  C --> T
~~~

前端 session Pinia store 管理身份/资料和能力开关；features/types.ts 描述跨页面数据。api.ts 是新页面唯一请求边界，页面动作有加载、失败提示及重复点击保护。编辑器只向 WorkbenchService 保存一次完整路书树，日期、排序、预算与版本在后端同一事务处理。

路书领域通过 TripRepository 使用 JDBC：主表、全部有效天数、全部有效节点各读取一次。WorkbenchService.load 使用只读事务取得一致快照，不再依赖 MyBatis clearCache。其他用户/成员基础查询仍使用 MyBatis；本轮没有替换全站持久层。写入先锁主表，再读取最新成员角色；成员移除也先取同一行锁，避免等待期间权限变化被旧快照绕过。

## 数据关系与不变量

Trip由用户所有，Day属于Trip，Item属于Day和同一个Trip。完整保存先检查所有已存在ID确属当前路书，再写树；节点跨天移动保留ID。修改不会接受作者、归属或删除标记。删除的节点和日期保留软删除记录，新建和排序通过实际行程数组决定。

完整保存锁定 Trip，检查 version 和字段白名单，标准化金额/小时/坐标/日期，再对比当前树。无变化直接返回且不写历史；有变化保存旧快照到 trip_revision，只写变化行和主表版本/预算。软删除只针对实际移除的 ID，新节点一次 INSERT 写齐字段。恢复旧版本走同一差异事务，允许重新激活本路书历史 ID，保留账单来源关联；克隆仍生成新 ID。版本历史保存在数据库，界面展示最近50条。费用按人民币两位小数存储；预算是节点预估之和，实际支出是独立账单之和。

公开作品通过square_post保存不可变视图；只有显式发布/更新操作替换快照。公开作者数据来自sys_user的公开投影，不包括邮箱、登录名、密码或令牌版本。private Trip API不会因为路书已发布就允许陌生人读取。clone只能读有效公开快照，新ID、作者与私密状态通过create统一产生。

post_interaction以(user_id,post_id,action_type)为主键；设置“点赞/取消点赞”状态可重复调用。计数从真实关系表汇总，避免写死like_count。评论仅能由作者删除。trip_share存独立snapshot_json和随机token摘要，公开作品下架不撤销分享，整份路书删除会撤销分享。

## AI事务边界

~~~mermaid
sequenceDiagram
  participant U as 游客
  participant Q as AI任务服务
  participant M as 免费确认后的模型
  participant D as 数据库
  U->>Q: requestKey + 规划要求
  Q->>D: QUEUED (唯一请求标识)
  Q->>D: RUNNING + 预扣应用配额
  Q->>M: 外部流式调用（无数据库长事务）
  M-->>Q: 完整JSON + DONE
  alt 生成
    Q->>D: 校验后一次性保存私密草稿 + SUCCEEDED
  else 修改
    Q->>D: 预览 + baseVersion
    Q-->>U: 当前/建议安排
    U->>Q: 确认
    Q->>D: 版本检查 + 历史记录 + 保存 + APPLIED
  end
~~~

网络错误、截断、解析/结构校验失败时没有部分行程落库，并通过事务退回预扣应用配额。应用配额不是供应商免费余额的替代品，供应商开关必须先核实。任务状态通过具名SSE事件输出jobId；前端使用TextDecoder+帧缓冲处理跨块文本，连接失败可查持久任务状态。修改提案不会在确认前更新路书。

## 地图与天气

没有位置的节点保留“待确认”，没有路线的路段保留“暂无路线”，不补城市圆形散点或直线。当日点序依据路书，步行/驾车逐段请求实际polyline、距离和时间。查询返回tripVersion；前端在日程/方式/版本/未保存状态变化时使旧结果失效，过期响应不更新当前界面。

POI由用户核对候选后关联ID，运行时再从供应商读取坐标；不保存整份供应商响应、不建立全量POI缓存。使用高德坐标与高德底图。天气按实际预报日期匹配，日期超限显示未知，天气调整仍走AI预览/确认。当前没有启用真实供应商凭证，适配器契约测试不代表在线服务已验收。

## 验证与部署边界

JWT密钥来自本机配置/环境，BCrypt存储密码，tokenVersion使改密/全设备退出后的旧令牌失效。头像只接受实际PNG/JPEG，检查尺寸后重编码为256px PNG，随机文件名，不采用用户上传路径。HTTP错误使用401/403/404/409等真实状态。

独立Flyway迁移可复现演示/测试库；原库从未迁移。当前按单实例本地演示设计。公开部署还需要HTTPS、外部服务免费授权确认、数据库备份与历史凭证处理，以及实际线上运维方案；本轮未部署公网或推送Git远端。

## 第二轮接口与页面组织

`TripWriteDTO` 只接收可编辑字段；归属、软删除、预算、天数、排序和日期由服务端决定。旧节点/天数/排序写入口返回 410，旧 AI 直接修改入口返回 409，统一要求工作台保存或提案确认。

广场 GET /api/community/posts 使用更新时间和 ID 的游标，返回 PostPageDTO；游标绑定搜索词和作者筛选，改变条件后需要从首屏重新查询。互动计数增加 idx_post_action，广场增加排序和作者索引。小测试库全站查询的优化器仍可能扫描/排序，详见实测记录；包含匹配搜索未被描述成索引全文搜索。

编辑器草稿位于 useTripDraft，AI 监听/轮询/清理由 useAiTask 管理；DayNavigation、PlanEditor、HistoryDialog、ShareDialog、PoiDialog、AiProposal 承担对应界面。useLatestQuery 使搜索与公共页路由读取只接收最新响应。Pinia 继续只管理会话、资料和能力开关。

AI 幂等以 type/tripId/prompt 的稳定摘要判断，包括唯一键竞争后重新查询的路径；预扣保存 quota_reserved_date，失败退款不会扣减新的每日计数。SSE 安装调度句柄后再次检查关闭状态，即时终态也能释放调度。部署仍为单实例，未宣称跨实例调度。

## 2.5 轮地理查询与会话收尾

GeoService 保持 POI 引用优先、无引用时才使用有效已有 GCJ02 坐标。请求上下文只复用同一 POI 的解析坐标/未找到结果，不包含节点身份，也不跨请求缓存。单调时钟控制路线 30 秒总期限，单次调用最多 15 秒且受剩余时间约束，超时返回 504。

useGeoQueries 在路由组件内分别管理路线/天气请求、35 秒超时、取消与代次判断；当前页面路线可复用，显式刷新重新请求。地图 SDK 共享一次配置/脚本加载 Promise，10 秒期限；失败移除自己创建的脚本，重新加载可重试。取消或卸载后旧响应/错误/绘图不会覆盖新页面。

api.ts 在 401 时比较当前令牌与请求令牌，防止旧会话请求退出随后新登录的会话。DTO/数据库不迁移，外部在线能力继续关闭。
