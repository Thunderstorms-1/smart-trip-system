# 第四轮：真实 AI / 地图 / 天气接通

日期：2026-10-05。分支：`feat/provider-integration`。基线：`0ae614d`。

## 本轮目标

在不绕过免费额度保护、不暴露本机密钥、不修改原 `smart_trip` 数据库的前提下，完成真实外部能力的接通准备与在线验收。第三轮行程诊断闭环继续作为稳定基线。

## 当前本机状态

- AI：本机已存在 API Key；`enabled=false`，`free-quota-verified=false`，因此不会调用外部模型。
- AI 模型配置：百炼 OpenAI 兼容端点 + `qwen3.8-flash`。
- Geo / Weather / Map：本机尚未配置高德 Web 服务 Key、JS Key 与安全密钥，因此保持不可用。
- 产品不会使用测试替身冒充真实 AI、路线或天气结果。

## 安全门槛

外部能力必须同时满足：功能开关开启、免费权限已人工确认、所需 Key 已配置。任一条件缺失时能力接口返回不可用，并提供不含密钥的状态码：

- `DISABLED`：本机明确关闭。
- `QUOTA_UNVERIFIED`：尚未确认账号实际免费额度或接口权限。
- `KEY_MISSING`：服务端 Key 缺失。
- `BROWSER_KEY_MISSING`：高德 JS Key 或安全密钥缺失。
- `READY`：本机配置门槛满足；仍需通过最小真实请求完成在线验收。

## 在线验收顺序

1. 在供应商控制台确认账号地域、免费额度、有效期、接口权限和额度耗尽后的行为。
2. AI 先做一次最小非业务请求，确认模型 ID、鉴权、SSE 格式及实际免费额度；成功后再验证 SmartTrip 生成任务。
3. 高德先验证 POI 搜索，再验证单段步行/驾车路线和近期天气，最后验证 JS 地图。
4. 每项都记录真实响应时间、失败状态和产品页面表现；不做高频或批量真实调用。
5. 在线验收通过后才把对应 `free-quota-verified` 保持为 true；失败则恢复关闭。

## 本轮已完成的代码准备

- `AiProperties` 默认配置与示例文件统一为百炼 `qwen3.8-flash`，移除旧 DeepSeek / 模拟响应误导注释。
- `AiProvider` 与 `GeoService` 提供安全可诊断状态，不返回任何密钥内容。
- `/api/capabilities` 在原有布尔能力字段之外返回 `status`，旧前端调用保持兼容。
- 前端在 AI 生成页和行程诊断页区分“关闭 / 免费权限未确认 / Key 缺失”，避免把所有问题都显示为笼统的“未启用”。
