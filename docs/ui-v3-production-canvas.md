# V3 生产工作台画布（Phase 2D）

## 范围与完成边界

本轮将地图、真实地点标记、路线和天气接入既有 V3 工作台画布，属于已批准方向的普通扩展。根 `DESIGN.md` 仍是设计权威；`docs/design-preview-v3/PRODUCT.md` 仅提供已批准静态预览约束，原型数据不能成为生产数据。

**前端接线与真实禁用流程已验证，真实启用的外部 Provider 联调尚未验证。** 实际 `GET /api/capabilities` 返回 map、poi、route、weather 全部 false，状态均为 DISABLED。本轮未修改开关、配置、凭证、AI 或后端，不能称整个 Phase 2D 已实测上线。

基线为 `6d5a568`；代码与本文作为独立本地检查点，具体提交哈希以 Git 记录为准，未推送或部署。Phase 2A–2C 保持，Home、Quality 逻辑、NodeInspector、PlanEditor、AI 和后端无本轮差异；静态原型不改。

## 真实数据与原流程

- `GeoCanvas.vue` 经 Editor 的 canvas 插槽进入 `WorkbenchShell`，替换原非地理画布容器内容。`MapWeather.vue` 文件保留，但 Editor 不再调用它；查询仍复用 `useGeoQueries`，hook 只新增导出 `cancel: invalidate`，原算法不改。`amap-sdk.ts` 仅扩充中心、缩放和 Marker HTML 内容类型。
- 地点标记只取已保存节点 ID：来自已关联 POI 的 GCJ02 坐标，或匹配节点 ID 且 resolved 的路线 API point。坐标必须非空、有限且在经纬度界限内；未确认点不绘制，名称不自动生成坐标。没有有效坐标不初始化地图，初始中心来自确认点。
- 路线只绘制 available leg 的有效 API polyline，并要求两端对应已确认节点；不直接连接标记构造路线。距离或耗时缺失显示“未提供”，真实 0 保留，不用估算补齐。
- 天气只展示 available、日期匹配、城市与天气描述存在、温度完整有限的预报；允许负数和 0。查询时间、发布时间沿用数据源字段，发布时间缺失显示“未提供”，不推测远期天气。
- POI 继续通过既有 Inspector 显式搜索、关联，再由原整份路书保存流程持久化；不复制草稿，不新增地图自动搜索。点击标记或时间轴节点复用 `selectedNode` 打开原 Inspector，修改仍作用于同一节点对象。

## 查询生命周期与响应布局

行程编辑与路线天气页共享常驻画布：收起查询面板回到编辑时保留当前地图和结果；进入其他工具时取消查询并清理地图。原 trip/day/mode/version/destination/date/dirty 失效规则保留，画布 active 或地图、路线、天气 capability 变化会取消；SDK generation 与查询 epoch 拒绝迟到结果。加载地图、查询路线、查询天气均需用户显式操作；路线查询成功后可加载确认几何。按钮显示忙碌状态，支持取消、显式重试与结束后的焦点恢复，修改未保存时不能查询。

桌面查询面板位于右侧（340 px）；701–1100 px 使用 320 px 面板，打开查询时暂时隐藏时间轴以留出画布。700 px 及以下采用高度为画布 68% 的非模态底部查询面板，同时隐藏时间轴，保留一个主要操作面。查询内容独立滚动，退出标题区 sticky，支持 Escape、返回编辑与安全区。该查询面板没有替换 Phase 2C 的原生模态 Inspector Bottom / Full Sheet。

配色、Inter 与中文后备、白色稳定阅读面和少量轻透明浮层延续既有系统；无新图片素材或假地理装饰。真实 SDK 图层与全部覆盖面之间的实际避让仍需真实启用后核验。

## 既有系统五分类摘要

- 色彩：冷浅环境、白色工作面、深蓝灰正文/操作色，既有橙色用于地图标记与路线强调。
- 字体：Inter 与中文后备；查询标题桌面 19 px、手机 18 px，分区 15 px、正文 12 px，手机交通选择 16 px，天气温度 22 px。
- 布局：地图承担空间画布，日期/时间轴/Inspector 支持操作；窄屏查询临时重组，保留退出与画布。
- 材质：密集查询使用白色稳定阅读面，天气与来源信息使用轻透明浮层；既有圆角与柔和阴影延续。
- 行为规则：显式查询、能力门控、确认坐标、真实 polyline、缺失不补值、同一草稿与迟到结果拒绝。

Detector 仅运行一次，保留两条既有 Inter 常见字体 warning，不借此重新设计或新增规则。根 `DESIGN.md` 仍为项目原则格式，未采用 YAML / 八章节格式；根 `PRODUCT.md` 和 `.impeccable/design.json` 缺失。本文只记录既有元数据漂移，不修复或固化为新系统规则，也不新增视觉世界或 comp 合同。
